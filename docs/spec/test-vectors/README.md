# Conformance test vectors

Layout: `<area>/v<N>/*.json`. An implementation that claims version `N` of
an area must load **every** file in that directory and pass it.

Conventions:
- `u64` values (seeds, raw PRNG output) are hex strings `"0x%016x"`, because
  JSON numbers cannot hold 64-bit integers exactly.
- Every file has a `description`. The area's version field (e.g. `"rules": 1`)
  says which spec version it belongs to.
- Vectors are generated by `tools/reference/` (an independent Python
  reference implementation) and committed. Regenerating them must produce no
  diff for a frozen version.

## rules/v1 (`docs/spec/rules/v1.md`)

| file | checks |
|---|---|
| `splitmix64.json` | raw `next()` outputs |
| `bounded.json` | sequences of `below(k)` / `belowExcept(k, except)` from a fresh PRNG |
| `timing.json` | `itemLimit(n)`, `roundLimit(n)`, chrono total |
| `items-{classic,chrono,find}.json` | first 80 items `(n, pool, ink, word)` per seed |
| `rounds-tap.json` | first 40 tap rounds `(n, pool, inks, words, trueCard)` per seed |
