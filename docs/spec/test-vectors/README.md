# Conformance test vectors

Layout: `<area>/v<N>/*.json`. An implementation that claims version `N` of
an area must load **every** file in that directory and pass it.

Conventions:
- `u64` values (seeds, raw PRNG output) are hex strings `"0x%016x"`, because
  JSON numbers cannot hold 64-bit integers exactly.
- Every file has a `description`. The area's version field (e.g. `"rules": 1`)
  says which spec version it belongs to.
- Vectors are generated by `tools/reference/` (an independent Python
  reference implementation) and committed. Regenerating them must produce no
  diff for a frozen version.

## rules/v1 (`docs/spec/rules/v1.md`)

| file | checks |
|---|---|
| `splitmix64.json` | raw `next()` outputs |
| `bounded.json` | sequences of `below(k)` / `belowExcept(k, except)` from a fresh PRNG |
| `timing.json` | `itemLimit(n)`, `roundLimit(n)`, chrono total |
| `items-{classic,chrono,find}.json` | first 80 items `(n, pool, ink, word)` per seed |
| `rounds-tap.json` | first 40 tap rounds `(n, pool, inks, words, trueCard)` per seed |

## game/v1 (`docs/spec/game/v1.md`)

| file | checks |
|---|---|
| `encode.json` | descriptor (+ result) → record bytes (hex) and text code; CRC check value |
| `decode.json` | `valid`: text inputs (lower case, aliases, embedded, link) → descriptor; `errors`: inputs that must fail as `invalid` or `unsupported` |

## backup/v1 (`docs/spec/backup/v1.md`)

| file | checks |
|---|---|
| `encode.json` | entries + settings → record bytes (hex) and text code |
| `decode.json` | `valid`: text inputs (lower case, wrapped, embedded, trailing text, aliases, unknown settings key) → entries and settings; `errors`: inputs that must fail as `invalid` or `unsupported` |

## multiplayer/v1 (`docs/spec/multiplayer/v1.md`)

| file | checks |
|---|---|
| `invitations.json` | room id and relays → record bytes (hex), text code and Nostr room tag; parsing (lower case, wrapped, embedded, link, aliases, unknown transport tags) → room id and relays; `errors`: inputs that must fail as `invalid`, `unsupported` or `noTransport` |
| `events.json` | NIP-01 serialisation, event id and BIP-340 signature (zero aux randomness); events to reject |
| `messages.json` | event content → normalised message, or `null` when it must be ignored |
